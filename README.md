# 🍽️ Maqueta Web para Restaurantes & Locales de Comida

Ejemplo de página web interactiva y moderna para restaurantes, cafeterías, delivery y locales gastronómicos en **La Ligua, Valle Hermoso y alrededores**.

### ✨ Características principales:
- **Carta Digital Interactiva:** Con categorías (Carnes, Platos típicos en greda, Postres tradicionales, Bebidas).
- **Carrito de Pedidos WhatsApp:** Calcula totales y genera el mensaje de pedido con 1 clic.
- **Formulario de Reserva de Mesas:** Para confirmar asistencia los fines de semana.
- **100% Adaptada a Celulares (Mobile First):** Carga ultra rápida sin dependencias pesadas.

---
Sitio web de muestra desarrollado para prospección comercial en la Provincia de Petorca.
